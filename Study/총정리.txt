- ip, 서브넷마스크
	ipv4: 8bit(8진수: 0~255)의 4자리 ip ex) 255.0.255.255 > (2^8)^4 =43억개 -> 부족
	-> IPV6나옴: 16bit 4자리

	10.0.2.11/24에서 24가 masking, 10.0.2.11이 우분투의 ip주소, 10.0.2.가 네트워크주소, 11이 호스트주소, 
	Gateway주소도 10.0.2.1 ~ 10.0.2.254안에 있어여 함 ex) 10.0.2.2

	ip: 기기간 식별주는 번호
	port: 하나의 기기안에 프로그램을 구별해주는 번호

		find /etc -name "hosts" -exec cp {} ~/guests/ \;       =>      find 명령으로 /etc 디렉터리에서 hosts 파일을 찾아 ~/guests로 복사

-sed		sed <옵션> <명령> <파일이름>   -> sed에서 모든 -e의 실행들은 마지막에 오는 파일에만 실행!!!!!

	sed -n -e '1,$p' sample
	-n: 중복해서 출력하지마라 (pattern sapce꺼 출력하지마라, output만 보여줘라)
	-e: 이 뒤에 명령문올거다
	1: 첫번째줄
	,
	$: 마지막줄
	p: print

	-e '/010/p' : 010이 포함된 모든 행을 출력하라

	sed -n -e '/5555$/r add' -e '1,$p' sample
	-> 마지막($)이 5555가 포함된 행에 add파일을 더해라(r) 그리고실행하라(-e) 첫번째줄부터 끝까지 pring해라 sample파일을

	sed -i -n -e 's/[Mm]$/Male/g' -e 's[Ff]$/Female/g' -e 's/Bob/Mom/g' -e '1,$p' sample
		i=inplace, s=subsititute, g는 global: 한 줄에서 조건에 맞는 모든 문자열을 치환

-awk			awk <옵션> <awk 프로그램> <파일이름>	
	행=레코드, 열=필드형태 	: 전체=$0, 1열=$1, 2열=$2 ..... n열 $n
	awk ‘{ print “Name:”$1, “Num:”$2 }’ sample		-> " "안에있는거는 그대로 출력
	awk ‘$2 > 20 { print $0}’ sample			-> 조건문도 가능
	awk ‘{ sum += $3} END { print “SUM : “sum}’ sample
		-> END는 연산이 끝났음을 의미 -> 그냥 print하면 루프마다 나오지만 end하고 print하면 마지막 결과만 print
	vi awkp.script하고 안에 c언어 함수만들고print -> awk -f awkp.script sample  하면 script안의 함수를 sample에 적용

foreground/background 
	Foreground는 현재 터미널을 차지하고 실행되는 프로세스 -> sleep100하면 100초간 터미널에서 암것도 못함
	sleep 100 &	-> 명령 뒤에 &를 붙이면 Background에서 실행 -> 내 터미널에서는 계속 가능
	즉 백그라운드는 뒤에서 실행되는 여러 프로세스

signal: 실행 중인 프로세스에게 보내는 제어 메시지   : 종료!, 멈춰! 계속!
	ex)
	Ctrl+C
	→ SIGINT 전달
	→ 실행 중인 foreground 프로세스를 보통 종료

	Ctrl+Z
	→ SIGTSTP 전달
	→ foreground 프로세스를 일시정지

	Ctrl+D
	→ 시그널이 아님!
	→ EOF(입력 끝)를 전달
=> 주로 foreground한테 !!!!!!!

-kill		kill <-signal> pid번호
	주로 백그라운드!!! 프로세스처럼 키보드로 Ctrl+C를 바로 보내기 어려운 프로세스에는 PID를 이용해 시그널을 보내는 법
	ex) kill -SIGKILL 1234
	     kill -9 1234		=> 이 둘은 같음
	
	예시)
	1$ bash
	1$ more /etc/services   => more로 보는중에 터미널2로
	2$ ps -a | grep more 	=> 프로세스중 more포함된것만 grep해오기 => 이게 pts0!!!!
	2$ ps -a | grep pts/0	=> 하면 나옴 => 여기에 PID값도 포함
	2$ kill PID			=> 해당 PID번호로 죽임
	2$ kill -9 PID		=> 안죽으면 9옵션으로
	
	옵션
	1  = SIGHUP   : 터미널 연결 종료 / 설정 다시 읽기에 사용되기도 함
	2  = SIGINT   : 인터럽트 → Ctrl+C와 동일
	9  = SIGKILL  : 강제 종료 (프로세스가 무시할 수 없음)
	15 = SIGTERM  : 정상 종료 요청 → kill의 기본값

-쉘개념
	쉘: Shell = 사용자의 명령을 해석해서 Linux가 실행하도록 해주는 프로그램 ex) 터미널이 키오스크화면이고 내가 명령어로 주문하면 쉘이라는 직원이 주문을 처리->리눅스라는 주방이 작업
	-> bash, zsh, tcsh 등 여러 종류가 있으며 우리는 평상시에 bash사용하고 tcsh다운하면 저 쉘 사용하고 저거 쓰면 모양도 좀 바뀌고 형식도 좀 바뀌지만 명령어는 비슷
		-> 마치 chrome, edge, firefox처럼 여러개고 각 기능/성능도 다른것과 같은 느낌 => bash가 제일 흔함, tcsh가 제일 발전한 버젼
	$ sh로 실행 -> 여기서 ls등 가능, 나갈때는 exit

	cat /etc/shells	=> 여기에 쉘 리스트들 있음 ex) /bin/bash, urs/bin/tcsh등
	echo $SHELL	=> 현재 작업 shell 확인
