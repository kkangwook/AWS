------------------------------------------------------실습----------------------------------------------
1. web대신 bastion으로 private EC2접속

	Bastion 전용의 SG생성( 인바운드 규칙: ssh-사용자지정-Bastion의 사설ip/32) #Bastion만 접속가능하게
	-> Bastion EC2생성 -> Bastion에 SG적용 및 private EC2도 전부 적용
	-> Bastion EC2의 공인 IP로 접속 -> Private EC2로 접속 by ssh-agent or proxyjump




2. VM1의 Nginx를 Reverse Proxy로 만들어, 다른 VM의 웹페이지를 대신 받아오게 하는 실습(VM1 ip에 접속하면 VM2,3의 flask가 뜨게하기)

	(reverse-proxy: 클라이언트와 서버 사이의 중개자로 서버대신에 사람들의 요청을 받아서 분산처리)
	<구조>
	VM1-----------------*----------------VM2(이건 어댑터4끔)
	192.168.56.101        |			192.168.56.102
	nginx			   |			10.10.10.2 			3가지 intnet의 네트워크 같고 이름도 같아야함!!!!!!!!!
	10.10.10.1		   |			flask1
				   |
			           *----------------VM3
							10.10.10.3으로 바꿔줌, 이름도 intnet으로
							flask2


	VM2에서 flask설치하고 app.py파일 생성하고 app.run(host="0.0.0.0", port=5000)으로  #5000번으로열기
	-> sudo "$(which python)" app.py 로 계속 실행시켜놓음

	VM1의 nginx는 sites-enabled에 있는 심볼릭링크를 참조해서 설정 활성화하지만 실제 수정할때는 sites-available을 수정해야함
	->  sudo vi /etc/nginx/sites-available/default : location에 try_files주석처리하고 그 밑에 proxy_pass http://10.10.10.2:5000; 
	-> sudo nginx -t로 문제없는지 확인 -> sudo systemctl restart nginx -> 혹시몰라 sudo ufw disable
	-> 크롬으로 VM1의 ip접속하면 VM2의 flask가 잘 뜸

	VM3에서도 똑같이 flask만들고 내용만 다르게 -> sudo "$(which python)" app.py로 계속 실행시켜놓음
	-> VM1에서  proxy_pass http://10.10.10.3:5000;   으로 바꿔주고 restart만 해주면 VM3가 나옴





3. 로드 밸런싱: VM1에 접속하면 번갈아서 VM2,VM3 접속하게 하기

	VM1에서 sudo cp /etc/nginx/sites-available/default /etc/nginx/sites-available/sesac #기존 default파일을 sesac으로 복사해서 새로만듬
	-> sudo vi /etc/nginx/sites-available/sesac 해서 아래처럼 바꿈(upstream 맨 위에 추가, server안에도 추가)
	###############################################################
	upstream flask {
    		server 10.10.10.2:5000 weight=3;		# 3대1의 비중으로 요청 받겠다
     		server 10.10.10.3:5000 weight=1;		#둘다 weight지우고 두번째꺼에 대신 backup 하면 서버1 죽으면 서버2가 작동;
	}

	server {
    		listen 80 default_server;
        	root /var/www/html;
        	index index.html index.htm index.nginx-debian.html;

        	location / {
                	# proxy_pass http://10.10.10.2:5000;
                	# proxy_pass http://10.10.10.3:5000;
                	proxy_pass http://flask;             # 위의 새로 추가한 upstream flask내용을 가져오겠다
        	}

	}
	#############################################################

	-> 새로 만든 설정파일 심볼릭 링크로 활성화: sudo ln -s /etc/nginx/sites-available/sesac /etc/nginx/sites-enabled/sesac
	-> sudo nginx -t로 확인하니 중복된다고 나옴(설정파일이 default, sesac두개라)		
	-> 기존의 default설정파일비활성화 해주기: sudo unlink /etc/nginx/sites-enabled/default		
	-> sudo nginx -t로 다시 확인하니 ok사인 -> sudo systemctl restart nginx
	-> VM2, VM3둘다 켜진 상태에서 크롬으로 VM1 공인ip로 접속해서 새로고침 계속=> 이제 2번,3번 가중치에따라접속하게됨!!!!
